# 三层编钟刮奏：本地验收

用户未另附九条清单，以下按本次请求归纳。未推送、未发布 GitHub Pages。

1. **保留原场景**：`git diff --exit-code -- src/generated public` 通过；没有改原图片、视频、CSS、时间轴。新增透明 Canvas 为 fixed 覆盖层，`pointer-events:none`，不占布局空间。声音设置为独立悬浮控件，是本次明确要求的新增 UI。
2. **三层命中**：上层 12%–23%、中层 32%–50%、下层 55%–91%，相对钟架而非屏幕。优先支持带 data-rack-bell/data-layer 的真实 DOM 元素；本场景实际为整段视频，因此用百分比配置。已按视频 23–29 秒逐秒校准镜头拉远，并处理 cover 裁切。当前为 46 个可见钟位热区，不等同于文物的全部 65 件钟。三尺寸 D 键截图已保存；视频中烟雾遮挡区仍属于矩形近似命中。
3. **鼠标/触摸、去重与间隔**：三尺寸各完成 92 次双向鼠标发声、10 次下层触摸发声。每个方向的单次手势同钟去重；反向或重新开始可再奏。最小实测间隔 46.5ms。快速跨过多个钟时排队，不丢中间音；极快滑动时视觉/声音会依序追随，不承诺零延迟。
4. **音区与音阶**：按 x 从左到右递增，反向递减；自动断言双向音高顺序通过。统一 C 宫五声音阶 C/D/E/G/A，含上方 C 端点：下层 MIDI 36–48（C2–C3）、中层 60–72、上层 72–84。同一八度的钟位多于六个时有同音重复。
5. **速度力度映射**：代码核对为 clamp(abs(dx)/dt/1.5, 0.18, 1)，使用 CSS px/ms；速度提高时合成总线增益与 Canvas 脉冲强度同步增大，达到上限后保持。
6. **实时合成与尾音**：无音频采样文件。六分音比 1/2/2.76/5.4/8.93/13.3，各分音独立指数衰减，衰减时长 tail/(1+i*0.5)，高频更快。下层基础尾音 4.8s，中层 3s，上层 2.1s。运行时验证 ±5 cent 双振荡器、20ms 带通噪声、ConvolverNode 均存在。高音超出采样率安全上限的分音跳过，避免混叠。所有音高为实验合成映射，非文物实测音律。
7. **反馈仅绘于 Canvas**：暖金脉冲、扩散声波、下层扬尘、350ms 光标轨迹均由 Canvas 绘制，未对原钟图片施加额外变换。已检查反馈截图；减少动态效果设置下去除扬尘与拖尾，声波简化。
8. **控件与调试**：原生音量/静音/混响控件带可访问名称；自动验证静音开关和混响数值变更；D 切换命中框，输入控件内不触发调试。首次使用请点击/触摸画面或声音控件以解锁浏览器音频；浏览器未授予音频播放权限时，仅悬停不能绕过限制。
9. **离线和集成**：三尺寸在加载完成后使用浏览器离线模式测试发声通过，无外部 CDN 和音频请求。新增交互只用原生 JS、Canvas、Web Audio；宿主原有 React/GSAP 不变。离线启动需要本机项目和本地服务运行，不表示未缓存的远程网址能在断网后首次打开。构建及原三主钟的放大/长按回归另行执行。

## 文件与运行

- 实现：src/experiment/rackGlissando.js、rackAudio.js；main.jsx 仅安装/清理该交互层。
- `npm run dev -- --host 127.0.0.1 --port 5175`，访问 http://127.0.0.1:5175/b/ ，滚动至末段完整三层钟架。
- `node scripts/verify-rack.cjs`：三尺寸自动测试，结果 results.json；截图 idle/debug/feedback-尺寸.png。
- `npm run build`：生成本地构建，不发布。
